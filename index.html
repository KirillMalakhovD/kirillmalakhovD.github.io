TG Archiver

A personal tool of Kirill Malakhov. Not a public service, not distributed to anyone.

TG Archiver runs only on the owner's Mac. It saves the history of selected Telegram chats as Markdown files, sorts files received in those chats into project folders, and keeps these project folders in sync with folders on the owner's Google Drive, so that the owner and invited colleagues work with the same files.

Privacy Policy

Last updated: October 13, 2026.

Who uses it. The app is used only by its owner. There are no other users and no accounts.

What Google data it accesses. With the owner's consent, the app uses the Google Drive API to list, download and upload files in the project folders the owner selects in the app's settings.

How the data is used. Only to sync those folders between the owner's Mac and the owner's Google Drive:

  • project files and chat history are uploaded from the Mac to the selected Drive folders;
  • files that colleagues add to those folders are downloaded to the Mac;
  • the app never deletes anything on Google Drive.

Where the data is stored. Only on the owner's Mac and in the owner's Google Drive. Access keys are stored in the macOS Keychain. The app has no server of its own.

Sharing. Data obtained through Google APIs is never sold, shared with or transferred to third parties, and is not used for advertising or for training AI models. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be revoked at any time at myaccount.google.com/permissions.
